# CPU Manager 1.1.9

## Deutsch / English
- Versionsnummer auf 1.1.9 erhöht.
- Deutsche und englische Sprachwahl aus Version 1.1.8 übernommen.
- Sprachwahl und Bestätigungsdialoge (Ja/Nein bzw. Yes/No) bleiben erhalten.
- Prozessaktionen (Beenden, Sofort beenden und Dienst-Neustart) laufen weiterhin in Hintergrundthreads, damit die Oberfläche bedienbar bleibt.
- Bestehende Prozessschutz- und Berechtigungslogik bleibt unverändert.

## English
- Version number bumped to 1.1.9.
- German and English language selection from version 1.1.8 retained.
- Language selection and confirmation buttons (Ja/Nein or Yes/No) remain available.
- Process actions (terminate, force stop and service restart) continue to run in background threads so the UI remains responsive.
- Existing process-protection and permission logic remains unchanged.
